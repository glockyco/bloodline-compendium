# The Bloodline Compendium

A searchable reference, interactive maps and mechanics guides for players of [The Bloodline](https://store.steampowered.com/app/1159290/The_Bloodline/), built from the game's own data.

The project is in planning. Nothing is built or published yet. The planned design and its first deliverable are in [`openspec/changes/`](openspec/changes/).

## How it will work

The game's content is read offline from the installed game's cooked Unreal Engine packages. Each run regenerates the data from the game files, so extracted data never enters Git, and the published site is its only public form. Where the data leaves something uncertain or unknown, the site says so instead of guessing. A modded copy of the game runs only to capture map imagery and to check formulas against the game itself.
