# Spec Delta

## MODIFIED Requirements

### Requirement: Home and missing pages
The home page SHALL lead to every kind's list, the tools and the most asked-for item groups, with counts that match the lists. A missing URL SHALL show the site's missing-page view with search and links to every kind's list.

#### Scenario: Unknown URL
- **WHEN** a reader opens a URL that does not exist
- **THEN** the page says the page does not exist and offers search and every kind's list
